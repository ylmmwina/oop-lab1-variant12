# Лабораторна робота 1 — Варіант 12

Консольний застосунок «Мобільний зв’язок» з дисципліни об’єктно-орієнтованого програмування. Java 25, Maven, JUnit 5, Mockito та JaCoCo. Потрібен інтернет для першого завантаження залежностей.

## Що реалізовано

| Вимога | Реалізація |
| --- | --- |
| Ієрархія тарифів | Абстрактний `Tariff`; `VoiceTariff`, `DataTariff`, `CombinedTariff` |
| Список тарифів компанії | `MobileCompany` з власним списком |
| Загальна кількість клієнтів | `getTotalClients()` повертає `long` |
| Сортування за абонплатою | `sortByMonthlyFee()`, зростання, стабільний порядок для однакових цін |
| Пошук у діапазоні параметрів | `findTariffs(TariffCriteria)`, плата + хвилини + ГБ; усі межі включні |
| Інкапсуляція | Приватні незмінні поля; захисні копії списків |
| Поліморфізм | `List<Tariff>` та перевизначений `getType()` |
| Пакети | `model`, `service`, `app` |
| Мінімальна консоль | Один автоматичний сценарій без меню |
| Unit-тести | JUnit 5, Mockito; перевірка покриття JaCoCo |
| Git | Логічні коміти й `.gitignore` включено до архіву |
| Віддалений репозиторій | Потрібно виконати push у свій GitHub за `docs/GITHUB.md` |

У вихідній умові немає вимоги до окремого Word-звіту чи скриншотів. Пояснення та матеріал для захисту є в `docs/EXPLANATION_UK.md`.

## Відкрити в IntelliJ IDEA

1. Повністю розпакуй архів. Відкривай папку `mobile-company-lab1`, усередині якої є `pom.xml`.
2. У IDEA: **File → Open** → вибери `pom.xml` → **Open as Project**, якщо буде такий вибір. Дочекайся імпорту Maven.
3. **File → Project Structure → Project → SDK**: вибери встановлений **JDK 25**. Language level — **SDK default** або **25**, без preview.
4. **Settings → Build, Execution, Deployment → Build Tools → Maven**: Maven home — **Bundled (Maven 3)**. У **Runner → JRE** та **Importing → JDK for importer** вибери **Project JDK / JDK 25**. Назви пунктів можуть трохи відрізнятися між версіями IDEA.
5. Відкрий `src/main/java/ua/edu/lab1/app/Main.java`. Натисни зелений трикутник біля `main` → **Run 'Main.main()'**.
6. Очікувано: **4100 клієнтів**, тарифи за платою **120.00 → 200.00 → 250.00 → 450.00 грн**, результат пошуку — **Онлайн**, **Баланс**.

Не створюй новий Java-проєкт і не копіюй усі класи в один файл: структура вже готова.

## Тести та покриття

Відкрий панель **Maven** праворуч → **Lifecycle → verify**. Це компілює код, запускає всі тести, формує JAR і звіт покриття. Якщо панелі немає: **View → Tool Windows → Maven**. Якщо проєкт не розпізнано, натисни правою кнопкою на `pom.xml` → **Add as Maven Project**.

Після успіху відкрий у браузері `target/site/jacoco/index.html`. Поріг у `pom.xml`: **100% рядків та гілок** основного коду, без виключення класів. Це метрика виконаного коду, а не гарантія відсутності всіх можливих помилок. Окремі тести можна запускати зеленим трикутником у `src/test/java`.

Якщо Maven встановлено окремо та JDK 25 доступний у терміналі:

```shell
mvn clean verify
java -jar target/mobile-company-1.0.0.jar
```

Команда `mvn` у терміналі може бути недоступна навіть при наявності вбудованого Maven у IDEA. Тоді використовуй панель Maven, нічого додатково встановлювати не потрібно.

## Дані та обмеження моделі

- Усі назви, ціни та кількості клієнтів вигадані для лабораторної.
- Плата — **грн за календарний місяць**; хвилини й інтернет — включені пакети за цей місяць. ГБ тут є одиницею характеристики тарифу; перерахунку в байти немає.
- Плата має два десяткові знаки, `BigDecimal`, без округлення: наприклад, `120` стає `120.00`, а `1.001` відхиляється. Рядкове створення `new BigDecimal("120.00")` не додає похибки `double`.
- Кожен клієнт за припущенням моделі має один тариф. Тому підсумовуємо кількості; облік унікальних людей з кількома SIM-картками не реалізований і умовою не вимагається.
- Назва обов’язкова, числові характеристики невід’ємні. Нуль дозволений. Порожня компанія дає 0 клієнтів та порожній результат пошуку.
- Пошук повертає всі відповідні тарифи. Коли їх немає, результат — порожній список. Усі три діапазони діють одночасно (логічне AND).
- Без зовнішньої бази даних та файлу налаштувань: у завданні файл лише дозволений, але не обов’язковий.

## Де що знаходиться

- `src/main/java/ua/edu/lab1/model` — тарифи.
- `src/main/java/ua/edu/lab1/service` — компанія й критерії пошуку.
- `src/main/java/ua/edu/lab1/app/Main.java` — демонстраційні дані та виведення.
- `src/test/java` — тести кожного класу та консольного сценарію.
- `src/test/resources/expected-output.txt` — повний очікуваний результат.
- `src/test/resources/mockito-extensions` — налаштування Mockito без динамічного підключення агента; достатньо для mock абстрактного `Tariff`.
- `docs/GITHUB.md` — публікація зі збереженням готових комітів.
- `docs/EXPLANATION_UK.md` — пояснення для захисту.
- `docs/VERIFICATION.md` — фактична перевірка готового проєкту.
